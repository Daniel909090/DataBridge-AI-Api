# DataBridge AI API

DataBridge AI API is a Python-based project in development that aims to connect internal text data with an AI model through a simple API service.

## Planned Features
- Load and process internal documents
- Split text into chunks
- Retrieve relevant context based on a user question
- Send context and question to an AI API
- Return a structured response through an API endpoint
- Docker support for local deployment

## Technologies
- Python
- FastAPI
- OpenAI API
- Docker

## Project Status
In progress

## Goals
This project is being developed to demonstrate:
- API integration
- AI workflow design
- retrieval-augmented generation concepts
- data ingestion and chunking
- containerisation with Docker
